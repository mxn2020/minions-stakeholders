# Welcome to Minions Stakeholders

We're excited to introduce **Minions Stakeholders** — Stakeholder registry, roles, and communication preferences.

## What's Included

- **TypeScript SDK**: `npm install @minions-stakeholders/sdk`
- **Python SDK**: `pip install minions-stakeholders`
- **CLI**: `npm install -g @minions-stakeholders/cli`

## Getting Started

Check out the [documentation](https://stakeholders.minions.help) for a full guide.
