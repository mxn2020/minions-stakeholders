---
title: Installation
description: Install Minions Stakeholders packages
---

## TypeScript / Node.js

```bash
npm install @minions-stakeholders/sdk minions-sdk
```

## Python

```bash
pip install minions-stakeholders
```

## CLI

```bash
npm install -g @minions-stakeholders/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
