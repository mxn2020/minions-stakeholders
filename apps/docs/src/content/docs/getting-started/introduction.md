# Minions Stakeholders

Stakeholder registry, roles, and communication preferences

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-stakeholders/sdk`) — Core library for Node.js
- **Python SDK** (`minions-stakeholders`) — Python bindings
- **CLI Tool** (`@minions-stakeholders/cli`) — Command-line interface
- **Web App** — Interactive playground at [stakeholders.minions.wtf](https://stakeholders.minions.wtf)
